# SecureTunnel

SecureTunnel is a TLS 1.3 and SSH handshake visualizer.

## Features

- TLS 1.3 handshake simulation
- SSH handshake simulation
- Interactive frontend
- FastAPI backend
- REST API endpoints
- Visual display of handshake steps

## Technologies

- Python
- FastAPI
- Uvicorn
- HTML
- CSS
- JavaScript

## How to Run

### Backend

```bash
cd backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload
